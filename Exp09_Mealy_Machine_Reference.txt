Experiment 9: Mealy machine from the sample (binary input/output example)

States: q0 (initial), q1
Input alphabet: {0,1}; Output alphabet: {0,1}
Transitions (input/output):
  q0 --0/0--> q0
  q0 --1/0--> q1
  q1 --0/0--> q0
  q1 --1/1--> q1

This produces output 001 for input 001? Check the sample's transition table:
q0: 0 -> q0/output 0; 1 -> q1/output 0
q1: 0 -> q0/output 0; 1 -> q1/output 1
Build it using JFLAP's Mealy Machine / Transducer option. The exact .jff XML
format for transducers differs from ordinary finite automata, so this reference
is provided instead of a potentially invalid automaton file.
